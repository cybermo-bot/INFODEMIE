# Daily workflow

Analyst: inspect source freshness before interpreting volumes. Import authorized redacted material, review the redaction preview and provenance declaration, and commit it. Open a case, assign an owner/reviewer and document potential harm and missing score components. Request evidence retrieval; lexical retrieval is a baseline, not verification.

Scientific reviewer: inspect the claim context, original language and exact passages. Check issuer, edition, population, date and source permission. Confirm or revise the assessment with a rationale. Preserve conflicting/insufficient conclusions; factual conclusions need approved supporting/contradicting evidence. Re-review stale assessments after source/document changes.

Communication editor: create each language/script/channel variant from a current confirmed assessment. Request scientific review, then document language and meaning review. Wording changes reset review. Derja wording must be checked by a local language reviewer; machine translation is not scientific equivalence.

Institutional approver: approve only after scientific and language checkpoints. Approval binds immutable text/version and evidence snapshot. Publish manually outside the application if institution policy permits, then record the real channel and actual time. No platform button sends public messages.

Analyst follow-up: at 48 hours, seven days and 30 days document collected item windows, source changes/outages and coverage comparability. Small/zero baselines require absolute counts; observed changes do not prove causality. Record lessons and unresolved questions.

Operator: inspect failed jobs and source state; retry after fixing configuration/permission. Do not turn an unavailable vendor API into synthetic live coverage. Contact actual configured owners under the institution’s staffing policy; no recipients are invented by this software.

Administrator: deactivate only scoped accounts; configure exact permitted RSS feeds and documented rights. Maintain evidence approval separately from monitoring permission. Never use an administrator account to substitute for scientific approval.
