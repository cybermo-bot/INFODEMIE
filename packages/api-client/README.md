# @pnsi/api-client

Typed TypeScript client for the PNSI API.

- `openapi.json`: schema exported from the FastAPI app (no server or database needed).
- `src/schema.d.ts`: types generated by `openapi-typescript`. Do not edit.
- `src/index.ts`: `createPnsiClient()` (openapi-fetch, cookies included, CSRF header added on unsafe methods) and `unwrap()`.

Regenerate after any API change, from the repository root:

```
make api-client
```

A backend test fails when `openapi.json` is out of date.
